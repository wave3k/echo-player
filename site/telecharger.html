Installer Écho

Choisis ton système : le lien télécharge directement le fichier de la dernière version. Aucun compte n'est demandé.

Dernière version : 1.4.0 · toutes les versions et leurs notes

Windows 10 et 11

Installateur Windows (.exe)

Le format recommandé pour un usage personnel. Écho apparaît dans le menu Démarrer, et les mises à jour se font ensuite depuis l'application.

Télécharger le .exe

Format entreprise : .msi

Debian, Ubuntu, Linux Mint, Pop!_OS…

Paquet .deb

Installe-le avec le gestionnaire de paquets. Les dépendances sont tirées automatiquement et l'entrée de menu est ajoutée.

Télécharger le .deb

Dans un terminal : sudo apt install ./Echo_*.deb

Toutes les autres distributions

AppImage

Un seul fichier, aucune installation. Rends-le exécutable, puis lance-le.

Télécharger l'AppImage

Dans un terminal : chmod +x Echo_*.AppImage

Compiler depuis les sources (Linux)

Il faut Rust et les dépendances système de Tauri 2 (WebKitGTK), voir le guide Tauri.

git clone https://github.com/wave3k/echo-player.git
cd echo-player
./packaging/build.sh
./packaging/install.sh

Aucun droit administrateur n'est nécessaire : tout est installé dans ~/.local. Écho s'ouvre ensuite depuis le menu des applications, ou avec la commande echo-player.

Mises à jour

Écho vérifie les nouvelles versions toutes les six heures. Tu peux les installer automatiquement, ou seulement être prévenu, au choix dans les réglages. Chaque version est signée : Écho refuse un fichier qui ne vient pas de lui.

Le paquet .deb ne se met pas à jour depuis l'application : repasse par cette page pour installer la version suivante.
