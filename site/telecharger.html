Installer Écho

Les fichiers de la dernière version sont sur la page des publications GitHub. Écho te signale ensuite les nouvelles versions.

Voir la dernière version

Choisir le fichier

SystèmeFichierComment l'installer
Windows 10 / 11Echo_x.y.z_x64-setup.exe
ou .msi		Double-clic, puis suis l'installateur.
Debian, Ubuntu, Mint…Echo_x.y.z_amd64.debsudo apt install ./Echo_*.deb
Autres distributions LinuxEcho_x.y.z_amd64.AppImagechmod +x puis double-clic.

Installer depuis les sources (Linux)

Il faut Rust et les dépendances système de Tauri 2 (WebKitGTK), voir le guide Tauri.

git clone https://github.com/wave3k/echo-player.git
cd echo-player
./packaging/build.sh
./packaging/install.sh

Aucun droit administrateur n'est nécessaire : tout est installé dans ~/.local. Écho s'ouvre ensuite depuis le menu des applications, ou avec la commande echo-player.

Mises à jour

Écho vérifie les nouvelles versions toutes les six heures. Tu peux les installer automatiquement, ou seulement être prévenu, au choix dans les réglages. Chaque version est signée : Écho refuse un fichier qui ne vient pas de lui.

Le paquet .deb ne se met pas à jour seul : il faut repasser par la page des publications.
